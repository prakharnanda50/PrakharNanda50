## Background

Programming assignments are graded in large batches and staff cannot compare every submission with every other. Some students have begun to submit code generated by AI tools.

## Proposal

Build a source-code analysis system for academic integrity. Output for AI-generated code must be presented as indicators and signals, never as a claim of certainty.

## Desired capabilities

- AST-based comparison
- structural similarity detection
- logical-pattern comparison
- similarity reports
- LMS integration
- professor dashboard

## Open questions
