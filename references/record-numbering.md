# Record numbering

| Prefix | Meaning | Example |
|---|---|---|
| AR-NN | Archive record (current numbering) | AR-09 |
| A-NN / ANN | Legacy export numbering, used in older spreadsheets | A09 |
| MN-NN | Meeting note | MN-14 |
| CAMPUS-NN | Dataset series tied to an archive record | CAMPUS-03 |
| DG-NN | Diagram | DG-04 |
| DR-XN | Working draft | DR-C1 |
| R-NN | Review register entry | R-09 |
| IR / SL / RR | Intake / status / review registers | SL-2024 |

Dataset series may carry a letter suffix when one record has several files.
