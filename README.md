# Campus Innovation Archive

An internal archive of historical campus technology proposals,
research notes, student surveys, meeting records, and experimental
concepts collected between 2022 and 2026.

This repository is primarily maintained for archival and research
purposes.

Some records are incomplete or duplicated because they were imported
from older project folders.

This archive contains ten major campus technology proposals collected
over several years. Some proposals were abandoned, some merged, and
some were never implemented.

## Contents

| Section | What it holds |
|---|---|
| [Archive](archive/) | Year-by-year intake registers, status logs and review registers |
| [Research](research/) | Surveys, observations, interviews, reports and field notes |
| [Proposals](proposals/) | The proposal documents, plus working drafts |
| [Meeting Notes](meeting-notes/) | Committee minutes, numbered MN-01 onwards |
| [Datasets](datasets/) | Campus, student and infrastructure data exports |
| [Diagrams](diagrams/) | Maps, flows and concept sketches |
| [References](references/) | Charter, numbering rules, registry export, citations |

Start with [index.md](index.md) for the list of records.

## Notes for readers

* Administrative exports (registry extracts, access logs, queue
  listings) live in dot-prefixed folders such as `.archive/` and
  `.review/`. Most file browsers do not list these by default: use
  `ls -a`, or enable "show hidden files".
* The full change history of the archive is available through the
  repository commit log.
* See [references/archive-guide.md](references/archive-guide.md) for
  naming conventions and the meaning of status labels.

Maintained by the Campus Innovation Committee secretariat.
